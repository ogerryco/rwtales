Este bloque no debe sentirse como biografia literal ni como clip musical generico. La funcion es preparar la idea de que James ya estaba dejando pistas emocionales en canciones como `The Unforgiven`, `The God That Failed` y `Mama Said`, antes de entrar al conflicto de `Some Kind of Monster`.

Se privilegian objetos, estudio, guitarras, libretas, control room y metaforas visuales. No se usan musicos genericos. Si se mete el clip candidato real de `The God That Failed`, debe ir muy breve y solo si no rompe el ritmo.
