# Script largo v13 marcado para TikTok vertical v1

Fuente: `script_long_v13_oralidad.md`

Uso: este documento conserva el orden del script largo, pero marca que parrafos tomar para construir el video corto vertical. Los tiempos son estimaciones editoriales, no timecode exacto del render final.

Leyenda:

- `USAR`: entra casi completo.
- `USAR COMPRIMIDO`: tomar solo la idea central o una frase.
- `USAR PUENTE` / `USAR REMATE` / `USAR GOLPE`: tomarlo como frase breve de transicion.
- `OMITIR EN SHORT`: dejar fuera para mantener tension y duracion.

## Nota de apertura

Antes del primer parrafo marcado, abrir con el clip vulnerable de James en So What/Brasil/intro aprobada: 2 o 3 frases maximo. Despues entra la voz con P001.
